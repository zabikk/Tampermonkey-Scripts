# Tampermonkey Userscripts

A collection of custom Tampermonkey userscripts for web automation and workflow enhancements.

## Installation

Click **Install** next to any script below. Tampermonkey will automatically detect the `.user.js` extension and open the install dialog.

| Script | Description | Quick Install |
| :--- | :--- | :--- |
| **DSP Fleet Dashboard** | Route controls, EV metrics, and fleet status | [Install](https://raw.githubusercontent.com/zabikk/tampermonkey-scripts/main/scripts/dsp-fleet-dashboard/dsp-fleet-dashboard.user.js) |
